Item 1 — Widen the Phase B filter first

Phase B builds _synchronised_units from entry state == SYNCHRONISED. Once UNLOADING exists, that filter must become entry state ∈ {SYNCHRONISED, UNLOADING}.

An unloading unit is on the bus, producing at MSL, and tracking down through the loading layer. If the filter is not widened it stops being written entirely and freezes at whatever output it last held — and the symptom is a unit that quietly stops responding, not an error. The write guard cannot catch it; a missing write is not a double write.

Do this before adding the state, so there is never a commit where UNLOADING exists and the filter does not know about it.

Item 2 — State machine

Add UNLOADING to TurbineState. Remove RAMPING, AT_TARGET, TRANSITIONAL.

AT_TARGET and TRANSITIONAL are set by no code path and report on-bus through is_synchronised, so a unit in either would be credited toward N−1 firm capacity with a frozen output and no writer. RAMPING disappears because on-bus ramping is no longer a state — it is the continuous behaviour of a SYNCHRONISED unit whose setpoint differs from its output.
