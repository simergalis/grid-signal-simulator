RE-READ THE CENTRAL PHYSICS BEFORE WRITING ANYTHING
P_served is NOT a clamp on P_demand. Load is FULLY SERVED even when
generation cannot meet it; the deficit comes from rotational kinetic
energy and frequency falls. P_served steps down ONLY when a protective
device removes load. A state where P_generation < P_served is physically
real and must be representable.

  P_served = P_demand - cumulative shed/trip load removal
  P_unserved = P_demand - P_served
  P_imbalance = P_generation - P_served

Any implementation using min(), a ratio, a clamp, or any continuous
function of generation to produce P_served is wrong and will be rejected.

PHASE 3 - SWING EQUATION, SUB-STEPPED
    2*H_agg/f0 * df/dt = (P_mech - P_elec)/S_base - D_eff*df
    f0 = 60 Hz

D IS COMPUTED PER TICK, NOT CONFIGURED AS A SCALAR:
    D_eff(t) = (P_cooling_demand(t)/P_demand(t))
               * fixed_speed_cooling_fraction * d_motor

IT load behind UPS/rectifiers is constant-power and frequency-decoupled:
zero damping. VFD cooling: zero. Only across-the-line induction motors
contribute, via affinity laws.

Expected magnitude at present operating point: D_eff ~ 0.13. Conventional
power system models use D = 1 to 2. If your implementation produces a
value near 1, it is applying damping to IT load and is wrong - report it
rather than scaling it.

Integrate at dynamic_step_s inside each 5 s tick. Spec 3.1's 5 s cadence
is the FORECAST refresh floor and is a different quantity from the
dynamic integration step. Do not conflate them.
Constraint: dynamic_step_s <= (shortest protection delay)/10. Assert it.

ACCEPTANCE: report df/dt, nadir, and time-to-nadir for an 18 MW deficit
with one 15 MW unit on bus. Report D_eff at that tick. Confirm nadir
resolution is unchanged when the outer tick rate is varied.
STOP AND REPORT.

PHASE 5 - PROTECTION AND SHED
Implement as ENVIRONMENT, not as a GridSignal function. Spec 28.4/28.7
place protective functions outside GridSignal's scope: the simulator
models them, GridSignal never commands them.

  - staged UFLS: threshold, delay, block, all from catalogue
  - 81U generator trip: threshold and delay from catalogue
  - a shed removes load; P_served steps down by the block
  - block allocation across compute and cooling comes from the block
    definition. Do NOT apportion by ratio.
  - terminal tripped run state: run ends, state recorded, VALID outcome
    not a crash

SPEC 28.4 INTERLOCK: a shed that has occurred is already in the measured
data. GridSignal curtailment must NOT treat it as unmet shortfall and
shed again. Implement the reconciliation entry, not a second shed.
