**Before generating tests, first find and cite the spec section(s) governing this feature** (likely in GS-DES-GRID-001 or the Forecast Engine Functional Spec) — confirm the intended behavior for source selection, aggregation, and PMS signaling before writing any test that asserts specific values. **Category A — Source Selection & UI State (≈10 tests)**
Selecting/deselecting individual sources (Battery, Grid, Fuel Cell), zero sources selected, all sources selected, single source selected, re-selecting an already-selected source, selection persistence across tab switches or page refresh, visual indication of selected vs. unselected state, selection during a live/running scenario vs. paused scenario.

**Category B — Aggregation Correctness (≈15 tests)**
For each valid combination of selected sources, verify the displayed aggregate MW equals the sum of *only* the selected sources' current output — not total plant output. Include: aggregate updates when a source's output changes while selected; aggregate does *not* change when an unselected source's output changes; aggregate updates immediately on selection/deselection (not on next tick only, or only on next tick — confirm which per spec); behavior when a selected source has 0.00 MW output; behavior when a selected source is in a fault/offline state — does it contribute 0 or get excluded from aggregation entirely; rounding/precision consistency between tile-level aggregate and per-source values.

**Category C — Signal Behavior to Switchgear/PMS (≈15 tests)**
Frame every test here around the advisory boundary — GridSignal recommends/advises the PMS, it does not command source transfers or write setpoints directly (per the inviolable advisory-boundary principle). Tests should verify: only selected sources' data/recommendations are transmitted; deselected sources stop being included in the advisory signal (and confirm whether "stop" means excluded from payload vs. included with a null/disabled flag — check spec); signal content on selection change; signal behavior on rapid toggle (selection flapping); no signal is sent that could be construed as a direct enable/disable command to a source (this should be an explicit test, not an assumption); confirm the PMS-facing payload/log shows advisory-only framing (e.g., "recommended," not "set" or "enable").

**Category D — Edge Cases & Error States (≈10 tests)**
Selecting a source that goes offline mid-selection; selecting during a queued/hold state; conflicting rapid clicks (double-click, selecting and deselecting within one tick); selection state when scenario is stopped/reset; selection state under multi-tenant load (does this tile aggregate per-tenant or plant-wide — check spec); behavior when all selected sources simultaneously report 0 MW; malformed or missing source-state data (does the tile fail gracefully or show a stale/last-known value); accessibility/keyboard-only selection if applicable.
